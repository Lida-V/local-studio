# PCリソースの表示

画面上部の **PCリソース** を押すと、右側に詳細パネルが開きます。閉じていてもCPU・RAM・VRAMの使用率は上部で確認できます。詳細にはGPUの稼働率・温度、RAM/VRAMの使用量と空き、モデル保存先とプロジェクト側のディスク容量を表示します。

タスク欄は会話・画像理解、Anima、Qwen Image 2.1、MiniMax H3、LoRA準備を選べます。現在のチャットの操作が分かる場合は自動選択します。他の生成ジョブの対象が分からない場合は手動で選んでください。「必要目安を見る」で、重み保存容量、設定、動作確認PC、必要量の計測状況を確認できます。

最低RAM/VRAMをまだ測れていないタスクは **未測定** と表示します。重みの保存容量、現在の実測RAM、動作確認PCの搭載量は、最低必要量とは異なります。画像・動画生成では会話モデルを一時解放してGPUを交代するため、両モデルの容量を単純に足して判断しないでください。LoRAは準備導線であり、実学習の必要量は未検証です。

約3秒ごとに更新します。非表示の間は計測を休止し、更新に失敗したら取得時刻と過去の値を表示します。未取得は空き容量0として扱いません。GPU詳細はNVIDIA対応です。会話エンジンのRAMは所有プロセスを確認できた場合だけ表示します。共有ページを含む合計で、GPU使用量はPC全体の値です。

CLIの `Studio-CLI.cmd resource-status`、Codex/Claude用MCPの `resource_status` でも同じ情報を取得できます。監視はモデルの起動・生成・学習を開始しません。

会話の読込・推論状態とエンジンの実測RAMはStrata使用時の計測です。llama.cpp使用時もPC全体とComfyUIの計測は利用できますが、会話専用の値は未取得になります。

UI更新を配備した後は、未送信の入力を保存してLocal Studioを閉じ、もう一度開いてください。画面の終了と、バックエンドを全停止する操作は別です。
